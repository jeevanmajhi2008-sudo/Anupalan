# Anupalan


AnuPalan tracks AICTE approval applications and compliance in one place. It routes each application through scrutiny, the Expert Visit Committee (EVC) and SAC/SHC, and keeps track of undertakings and document renewals. It sends alerts before deadlines are missed.

Features:-

- Automatic workflow routing and pendency dashboards
- EVC scheduling and inspection tracking
- Reminders for undertakings and document expiry, with escalation
- A public complaint site, with an AI chat bot in English and Hindi
- An officials' site that receives complaints live
- An audit trail of every action
